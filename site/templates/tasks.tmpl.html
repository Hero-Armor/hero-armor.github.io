Як оновлювати задачі

Задача — це запис у data/tasks.json: 
{ "task": "Що зробити", "system": "audio | solar | lights | armor | project",
  "status": "todo | doing | waiting | done", "note": "деталі (опційно)" }
  1. Через Claude / агента logistics — найпростіше: «додай задачу…», «задача … готова», «що по задачах?». Агент править JSON, перебудовує сайт і публікує.
  2. Локально: відредагуй data/tasks.json → cd site && python3 build.py → git commit && git push — CI перевикладе Pages за ~хвилину.
  3. Прямо на GitHub (без клона): відкрий data/tasks.json → Edit, зміни статус чи додай запис, commit у main — CI сам перебудує сайт. Дзеркала-артефакти оновляться при наступній локальній публікації.
