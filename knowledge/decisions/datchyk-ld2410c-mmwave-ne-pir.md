# Чому

PIR сліпне при 35–43°C (радіус 3 м → 0.45 м): робот мовчав би весь день. Радар температуронезалежний, віддає відстань по UART (тригер рівно на 2.5–3 м + адаптивна гучність), налаштовується по BLE. Умова: діелектричне вікно ~60×60 мм у броні (ABS/акрил/склотканина) — 24 ГГц не проходить крізь метал.
